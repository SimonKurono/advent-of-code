# Advent of Code Solutions

This repository contains Python solutions for the Advent of Code programming challenges. Each solution is organized by day and focuses on clarity and algorithmic efficiency.

## Repository Structure

The project is organized into daily directories, each containing the necessary components to solve that day's challenge:

- `dayX/`: Directory for a specific day's challenge (e.g., `day1/`).
- `dayX/solution.py`: Python script containing the logic for Part 1 and Part 2 of the challenge.
- `dayX/input.txt`: Data provided by Advent of Code for the specific challenge.

## Getting Started

### Prerequisites

- Python 3.8 or higher is recommended.
- No external libraries are strictly required for the core solutions, though some may use standard library modules.

### Running a Solution

To execute a solution for a specific day, navigate to the root of the repository and run the Python script using the following command:

```bash
python3 dayX/solution.py
```

Example for Day 1:
```bash
python3 day1/solution.py
```
